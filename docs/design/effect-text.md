# Effect Text

Every item, heirloom, curse, rune and prefix, with the effect text the game shows today. The
game builds this text from each effect's blocks (`EffectCarrierDefinition.describe()`); nothing
stores it as written text. Dumped from the catalog on November 20, 2026 for the user's wording
pass (RF-036).

**How to use it:** write your wording in the **New wording** column, leave it blank to keep the
current text, and add notes where a rule reads wrong. The text step (TX1) then makes the game show
your wording. The intended rules are in [items.md](items.md) and [heirlooms.md](heirlooms.md);
where this text and those docs disagree, the docs say what the item should do.
